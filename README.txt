FUTUREPROOF COMPLIANCE SERVICES — STATIC VERSION 2
===================================================

No Node.js is required.

Open index.html directly in a browser, or use the VS Code Live Server extension.

PAGES
-----
index.html           Home page
services.html        Services
how-it-works.html    How the system works
assessment.html      Interactive business compliance assessment
consultations.html   Consultation scheduling (no public prices)
get-help.html        Call / WhatsApp / Support Ticket

EDITING BUSINESS DETAILS
------------------------
common.js contains the main phone, WhatsApp and email settings.

BRAND IMAGES
------------
assets/LOGO.jpeg is the current FUTUREPROOF logo image.
Other uploaded flyers are in the assets folder and are used across the site.

SUPPORT TICKET
--------------
The ticket form uses FormSubmit because this version has no backend/server.
The form sends to futureproofcompliance701@gmail.com.
The first real submission may trigger a one-time verification email from FormSubmit.
Open that email and confirm the address. After activation, future form submissions are delivered to the inbox.

ASSESSMENT DROPDOWNS
--------------------
The assessment includes:
- Industry/sector dropdown
- All Nigerian states + FCT
- LGA dropdown that updates automatically based on the selected state
- Employee range
- Turnover range

IMPORTANT
---------
The assessment score is informational only. It is not an official government rating, legal opinion or tax opinion.
